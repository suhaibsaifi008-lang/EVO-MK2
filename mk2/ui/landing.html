DEVELOPER QUICKSTART

How to Start EVO MK2

STEP 01 — CLONE REPOSITORY

git clone https://github.com/suhaibsaifi008-lang/EVO-MK2.git

STEP 02 — ENTER DIRECTORY & VIRTUAL ENVIRONMENT

cd EVO-MK2
python -m venv .venv
.\.venv\Scripts\Activate.ps1

STEP 03 — INSTALL DEPENDENCIES

pip install -r requirements.txt

STEP 04 — CONFIGURE .ENV (WAKEUP WORD: EVO)

ANTHROPIC_API_KEY=your_key
EVO_WAKE=1
EVO_WAKE_PHRASES=evo,hey evo,ok evo,wake up evo

STEP 05 — LAUNCH EVO MK2

python -m mk2.kernel
